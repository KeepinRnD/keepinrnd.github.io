第1条 目的

本規約は、株式会社キピン((주)키핀、以下「当社」)が提供するクロビン(Klovin)サービスの利用に関し、当社と利用者との間の権利、義務および責任事項、利用条件と手続きなどの基本的な事項を定めることを目的とします。

第2条 用語の定義

  1. サービス — 当社が提供するクロビンアプリケーションおよびこれに付随する一切のサービスをいいます。
  2. 利用者 — 本規約に同意し、サービスを利用する満19歳以上の方をいいます。
  3. 投稿 — 利用者がサービスに投稿または送信した写真、文章、ストーリー、コメント、メッセージ、音声、レターなどをいいます。
  4. フォロー — 他の利用者の公開投稿を受け取って見る関係をいいます。フォローだけでは、トーク・通話はできません。
  5. 友達 — ある利用者が送った友達申請を相手が承認して成立した関係をいいます。トーク・通話・ふたりだけの空間は、友達どうしでのみ利用できます。
  6. ふたりだけの空間 — 友達ふたりだけが見る「ふたり」画面とトーク画面、およびその中のレター・記念日カード・デコ・ギフトをいいます。
  7. AIの友達 — 当社が人工知能で作成した仮想の人物のアカウントをいい、プロフィールとトークに「AI」と表示されます。
  8. ハート — サービス内で、友達申請、通話、ギフト、デコなど一部の機能に使う利用権をいいます(第8条)。決済で購入したハートを「チャージハート」、登録・招待・ギフトの積立などにより無償で受け取ったハートを「無料ハート」といいます。

第3条 規約の掲示と改定

  1. 当社は、本規約を利用者が容易に確認できるよう、アプリの設定画面と本ページに掲示します。
  2. 当社は、関係法令に反しない範囲で本規約を改定できます。
  3. 規約を改定する場合は、適用日と改定理由を明示し、適用日の7日前からお知らせします。利用者に不利な変更は30日前からお知らせし、アプリ内通知などで個別に通知します。
  4. 利用者が改定規約の適用日までに拒否の意思を表示しない場合、改定に同意したものとみなします。同意しない利用者は、利用契約を解約できます。

第4条 利用契約の締結

  1. 利用契約は、利用者が本規約とプライバシーポリシーに同意し、当社の定める手続きに従って登録を申し込んだ後、当社がこれを承諾することにより成立します。
  2. 登録は、Google アカウント、カカオアカウントまたは Apple アカウント(iPhone)のいずれかで行います。
  3. サービスは満19歳以上の方のみ利用でき、登録時に生年月日で確認します。
  4. 当社は、以下の場合には承諾を拒否し、または事後に利用契約を解約することができます。
    • 他人の名義・写真・情報を盗用した場合
    • 虚偽の情報を記載した場合(年齢・性別を偽った場合を含む)
    • 満19歳未満である場合
    • 過去に本規約違反により利用契約を解約された履歴がある場合
    • 技術上の事情または法令違反のおそれがある場合

第5条 サービスの内容

当社は、以下のサービスを提供します。

  1. プロフィール・発見 — プロフィール、好みと出会いの条件に合う人の発見・おすすめ、フォロー
  2. 投稿・ストーリー — 写真と文章の投稿(全体公開・友達のみ公開、コメント範囲)、24時間のストーリー、いいね・コメント、それぞれの言葉での翻訳表示
  3. 友達申請 — ひとことを添えて送る友達申請、スーパー申請(ボイスひとこと・申請一覧の一番上に表示)
  4. 翻訳トーク — 友達と文章・写真・翻訳ボイスメッセージ・ギフト・スタンプをやり取りし、受け取る人の言葉に自動翻訳
  5. 通話 — 友達との音声・ビデオ通話、リアルタイム翻訳字幕、登録した自分の声で聞く翻訳音声
  6. ふたりだけの空間 — ふたりの関係、初めて会った日から数えた日数、予約レター、記念日カード、テーマ・吹き出し・スタンプのデコ
  7. AIの友達 — 当社が作成したAIの友達とのトークと投稿(設定で非表示にできます)
  8. その他、当社が追加で開発し、または提携を通じて提供するサービス

サービスの利用に伴うデータ通信料は、利用者が契約している通信事業者のポリシーに従い、利用者が負担します。

第6条 翻訳・AI機能の性質と限界

  1. 翻訳、音声の文字起こし、通話の字幕と翻訳音声は、人工知能が自動で作成したものであり、不正確であったり、本来の意味と異なったりする場合があります。本サービスは専門の通訳・翻訳サービスではなく、公的・法的効力が必要な用途に使用してはなりません。原文はアプリであわせて確認できます。
  2. AIの友達は実在の人ではなく仮想の人物であり、AIの友達の言葉と写真は人工知能が作成したものです。AIの友達と実際に会ったり、金銭・物品をやり取りしたりすることはできません。
  3. 詐欺の疑いの警告は自動判定の結果であり、すべての詐欺を見つけられるわけではなく、正常なメッセージに警告が表示される場合もあります。
  4. 当社は、AIの応答と翻訳の正確性・完全性を保証せず、これを信頼して行った行為の結果について、当社に故意または重大な過失がない限り責任を負いません。

第7条 利用者の義務と禁止行為

利用者は、以下の行為をしてはなりません。

  1. 他人の写真・名前・アカウントを盗用し、または年齢・性別・国などを偽る行為
  2. 送金・口座・投資・暗号資産・ギフト購入など金銭を要求し、またはこれを目的に近づく行為(ロマンス詐欺など)
  3. 他のメッセンジャー・アプリにトークを誘導して詐欺・違法行為をしようとする行為、悪意のあるリンクを送る行為
  4. 脅迫・嫌がらせ・ストーキング・セクシャルハラスメント・差別・ヘイト表現など、他人に精神的苦痛を与える行為
  5. わいせつな内容、性的な内容、暴力的な内容、違法な情報、児童・青少年を対象とした有害なコンテンツを投稿または送信する行為
  6. 売買春・風俗のあっせんなど、違法な出会いを目的としてサービスを利用する行為
  7. 相手の同意なく、トーク・写真・通話の内容をスクリーンショット・録音・共有する行為
  8. 他人の著作権・肖像権などの権利を侵害する行為
  9. 営利目的の広告・宣伝・スパムを送る行為
  10. サービスのソースコードをリバースエンジニアリング・複製・改変し、または自動化プログラムで異常なリクエストを送る行為
  11. その他、関係法令または本規約に違反する行為

利用者は、自身のアカウントを自ら管理する責任を負い、アカウントが第三者に利用されていることを知った場合は、直ちに当社に知らせなければなりません。

第8条 ハート

  1. ハートは、友達申請(1日の無料回数を超えた場合)、スーパー申請、投稿ブースト、通話、翻訳ボイスメッセージ、ギフト、予約レター、記念日カード、デコなどに使われます。機能ごとのハート数と無料の範囲は、アプリの設定 → ハート料金案内に表示します。
  2. 受け取る人はハートを使いません。友達申請の承認、電話を受けること、メッセージを読むことと翻訳、ギフトを受け取ることは無料です。通話料金は電話をかけた人が支払い、受けた人が「私が払います」を選んだ場合は、そのときから受けた人が支払います。
  3. ハートを使うときは、期限が先に切れるハートから差し引きます。
  4. 期限 — チャージハートは購入日から5年、無料ハートは受け取った日から1年が経過すると消滅します。消滅の90日前からアプリに表示します。
  5. 無料ハートは、登録、友達の招待、受け取ったギフトの積立(チャージハートで送られたギフトの半分)などにより付与され、付与条件は当社が定めてアプリに表示します。無料ハートは、返金・現金との交換・譲渡の対象ではありません。
  6. 広告を最後まで見ると、その日の友達申請を1回無料で送れます(1日の回数はアプリに表示)。
  7. ハートは利用者本人のみが使え、他のアカウントに移したり現金に換えたりすることはできません。不正な方法で得たハートは、当社が回収できます。
  8. 退会時、残っているハートはすべて消滅します。

第9条 有料サービスと決済

  1. 当社は、ハートのチャージ商品とサブスクリプション商品を提供することがあり、商品ごとの価格と特典は決済画面に表示します。価格は、利用者の国・通貨を基準にアプリストアが表示する金額に従います。
  2. 決済は、Google Play(Android)または App Store(iPhone)が提供する決済手段でのみ行われます。当社は、カード番号などの決済手段の情報を収集・保管しません。
  3. サブスクリプションは、利用者が解約しない限り、決済周期ごとに自動で更新されます。利用者は、アプリストアのサブスクリプション管理画面でいつでも自動更新を解約でき、解約しても、すでに支払った期間が終わるまで特典は維持されます。
  4. 退会はサブスクリプションの解約ではありません。課金を止めるには、退会とは別にアプリストアで解約する必要があります。
  5. 当社は料金を変更することがあり、変更する場合は第3条に従って事前にお知らせします。
  6. 未成年者または第三者が名義人の同意なく決済した場合は、関係法令とアプリストアのポリシーに従って取消しを求めることができます。

第10条 申込みの撤回と返金

  1. 利用者は、電子商取引等における消費者保護に関する法律(전자상거래 등에서의 소비자보호에 관한 법률)に基づき、決済日から7日以内に申込みを撤回できます。チャージハートは未使用の部分に限り撤回でき、一部を使用した場合は、その範囲で撤回が制限されることがあります。
  2. アプリストアを通じて決済した場合、返金の受付・審査・支払いは、該当するストア(Google Play または App Store)のポリシーと手続きに従います。当社は、求めがあればストアの返金手続きをご案内します。
  3. 返金が行われた場合、その決済で受け取ったハートと特典は回収されます。
  4. 無料ハートと広告リワードは、返金の対象ではありません。
  5. 当社の責めに帰すべき事由によりサービスを正常に利用できなかった場合、当社は、その範囲に相当するハートを返還し、または返金します。

第11条 広告

当社は、サービスの画面(ホームフィードなど)に広告を掲載し、利用者が選んだ場合にリワード広告を表示することがあります。利用者が広告を通じて広告主と取引することは利用者と広告主との間の問題であり、当社は、当社に故意または過失がない限り、これについて責任を負いません。

第12条 サービスの変更・中断

  1. 当社は、サービスの内容を変更し、または一部を中断することがあり、重要な変更は事前にお知らせします。
  2. 当社は、設備の点検、停電・通信の途絶・天災地変などの不可抗力、サービスに必要な外部事業者(クラウド・翻訳・AI・通話事業者など)の障害がある場合、サービスを一時中断することがあります。
  3. 当社がサービスを完全に終了する場合は、少なくとも30日前にお知らせし、残っているチャージハートについては関係法令に従って返金します。

第13条 投稿の権利と管理

  1. 投稿の著作権は、その投稿をした利用者に帰属します。
  2. 利用者は、当社がサービスの提供に必要な範囲(保存、表示、他の利用者への送信、翻訳、サムネイルなどの形式変換、バックアップ)で投稿を利用することを許諾します。当社は、これを超えて投稿を利用し、または第三者に提供することはなく、広告や営利目的で利用することもありません。
  3. 全体公開の投稿はすべての利用者に、友達のみ公開の投稿とトークは友達に表示されます。他の利用者が画面を直接撮影することまでは当社が防ぐことはできないため、投稿する前に慎重にご判断ください。
  4. 投稿が関係法令や本規約に違反し、または通報を受けて確認された場合、当社はその投稿を削除し、または非表示にすることができます。
  5. 利用者が投稿を削除すると、サービス上には表示されなくなります。ただし、すでに相手に届いたメッセージは、相手のトークに残る場合があります。

第14条 利用契約の解約

  1. 利用者は、アプリの下部の「マイページ」タブ → 設定 → アカウントを削除から、いつでも利用契約を解約(退会)できます。
  2. 退会すると、アカウント、プロフィール、投稿・コメント・ストーリー、友達・フォロー関係、トークとふたりだけの空間、自分の声、残っているハートが削除され、復元できません。トークとふたりだけの空間はふたりで一緒に使う場所のため、相手の画面からも消えます。
  3. 関係法令に基づき保管しなければならない決済記録などは、プライバシーポリシーで定める期間保管されます。
  4. 当社は、利用者が第7条に重大に違反した場合、事前に通知したうえで利用契約を解約できます。ただし、他の利用者の安全に差し迫った危険がある場合は、先に措置を講じた後に通知することがあります。

第15条 利用制限

  1. 当社は、利用者が本規約に違反した場合、警告、投稿の削除、機能の制限、一時停止、永久利用停止などの措置を講じることができます。
  2. 利用者は、他の利用者の投稿・コメント・メッセージ・プロフィールを通報し、またはブロックできます。ブロックすると、お互いのプロフィール・投稿・ストーリーが表示されなくなり、フォロー・友達関係が解除されます。相手には通知されません。
  3. 当社は、措置を講じる前に、理由・期間・異議申立ての方法を通知します。ただし、他人の安全や権利に差し迫った危険がある場合は、先に措置を講じた後に通知することがあります。利用者は、異議がある場合、当社に釈明することができます。

第16条 個人情報の保護

当社は、利用者の個人情報を関係法令に従って保護し、その処理に関する具体的な事項はプライバシーポリシーで定めます。

第17条 責任の制限

  1. 当社は、天災地変、戦争、通信・クラウド事業者の障害などの不可抗力によりサービスを提供できない場合、責任を負いません。
  2. 当社は、利用者の責めに帰すべき事由により生じたサービス利用の障害について、責任を負いません。
  3. 本サービスは、利用者どうしが知り合い、会話する場を提供するにすぎず、利用者間の会話・出会い・取引およびそれにより生じた紛争・損害について、当社に故意または過失がない限り責任を負いません。当社は、利用者の身元(名前・年齢・職業など)を保証しません。
  4. 本条のいかなる内容も、当社の故意または重大な過失による損害、その他関係法令上制限できない責任を免除するものではありません。

第18条 安全のためのご案内

  • オンラインでしか知らない人にお金を送ったり、口座・身分証・パスワードを教えたりしないでください。お金を求められたり、他のアプリに移ろうと言われたりした場合は、通報してください。
  • 初めて会うときは、人の多い公共の場所で会い、家族や友人に予定を伝えてください。
  • 危険な状況にある場合や助けが必要な場合は、警察(112)、消防・救急(119)に連絡してください。詐欺の被害は、警察庁サイバー捜査局(경찰청 사이버수사국、182)に申告できます。

本サービスは緊急救助サービスではなく、当社は利用者間の会話をリアルタイムで確認していません。

第19条 準拠法と紛争解決

  1. 当社と利用者との間の紛争については、大韓民国法を準拠法とします。
  2. サービスの利用に関して紛争が生じた場合、当社と利用者は円満な解決のために誠実に協議します。
  3. 協議が成立せず訴訟が提起される場合は、民事訴訟法(민사소송법)に基づく管轄裁判所に提起します。
  4. 利用者が大韓民国以外の国に居住している場合にも本条を適用しますが、利用者が居住する国の消費者保護に関する強行規定が優先して適用される場合があります。
